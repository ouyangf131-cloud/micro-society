# 微型社会模拟器

在线试玩：<https://ouyangf131-cloud.github.io/micro-society/>

一个能在手机浏览器里直接玩的小社会：100 位虚拟居民会自己干活、买卖、合作、吵架、交朋友、分享食物、生孩子，也会因为饥饿、受伤或年老去世。你可以一天一天往前推，也可以让它自动跑，在图表里看贫富差距、人口和资源怎么变化。

- 只有一个 `index.html` 文件，不依赖任何外部库、字体或网络请求。
- 不用任何 AI 接口、API Key 或付费服务，所有计算都在你的浏览器里完成。
- 使用随机种子：相同种子 + 相同操作，结果完全一样。

## 怎么玩

1. 打开上面的网址（iPhone 竖屏可以直接用）。
2. 点 **前进 1 天** 看一天的变化；点 **前进 30 天** 快进一个月。
3. 点 **▶ 自动运行** 让时间自己走，再点一次 **⏸ 暂停**；暂停后再点就是 **继续运行**。可以在“速度”里选每秒 1 / 4 / 15 / 60 天。
4. **重置**：回到第 0 天。想换一个世界，就改“种子”里的数字（或点 🎲 随机一个），再点重置。也可以在网址后面加 `?seed=12345`。
5. 下方四个标签：
   - **图表**：财富分布直方图、基尼系数（贫富差距）变化、人口（在世/累计去世/累计出生）、每天资源消耗、每天合作/冲突/分享次数、市场价格。
   - **居民**：所有居民列表，可以排序和筛选；点任何人看详情（钱、食物、饱食度、体力、健康、性格、朋友和仇人、家人、最近经历）。
   - **今日事件**：当天发生的交易、合作、冲突、交友/结仇、治疗、救济、出生、死亡、转行。
   - **规则说明**：每条规则和每个参数的白话说明。

## 规则（白话版）

> 页面里的「规则说明」是程序直接从参数对象 `CONFIG` 生成的，数字永远和实际运行的一致。下面是同样内容的简化版，具体数字以页面为准。

- **居民**：每人有姓名、年龄、职业（农夫、渔夫、工匠、商人、医生）、技能熟练度、四种性格（善良、贪婪、攻击性、社交性）、现金、食物、物品（柴火/工具）、饱食度、体力、健康，以及和别人的关系分（−100 到 +100）。
- **工作**：体力和健康够的成年人每天工作，消耗体力。农夫、渔夫产食物，工匠产物品；产量受技能、健康、运气和“前一天有没有合作”影响。商人从每笔市场成交中抽手续费，医生给病人治病收费。
- **吃饭和休息**：饱食度每天下降，吃食物补回来；成年人每天用掉 1 件物品，休息得更好。饿到饱食度为 0、或累到体力很低，健康会下降；吃饱睡好健康会恢复。存着的食物每天会腐坏一点。
- **市场**：缺食物/物品的人去买，多出来的人去卖。越贪的人卖得越贵；买家从最便宜的买起，没钱就买不到。价格按“想买的量 vs 拿出来卖的量”每天自动涨跌。
- **社交**：每人每天见几个人（越外向见得越多，优先找朋友）。善良的人会把余粮分给饿肚子的人；见面时按概率发生 **冲突**（攻击性高、饿肚子、眼红比自己富的人更容易打起来，输家被抢钱并受伤）、**合作**（善良、关系好更容易，第二天产量提高）或闲聊。关系分超过 30 是朋友，低于 −30 是仇人，关系会随时间慢慢淡化。
- **公共救济**：每天向现金超过 100 元的人收一点税，平均发给现金很少的穷人。
- **死亡与继承**：健康降到 0 会去世（饥饿或伤病），65 岁以后有年老去世的风险。遗产给孩子，没有孩子就给关系最好的人。
- **出生**：关系很好、吃得饱、有点钱的两位适龄居民有小概率生孩子。孩子由父母喂养，16 岁成年后开始工作。
- **转行**：每 30 天，最穷的 10% 的人会改行去做最近最赚钱的职业。
- **基尼系数**：0 表示人人一样多，1 表示一个人拥有全部财富。

## 文件说明

- `index.html`：游戏本体（由 `src/` 里的三个文件拼成，可以直接打开）。
- `src/sim.js`：模拟引擎和全部参数 `CONFIG`；`src/ui.js`：界面、图表和规则说明生成；`src/template.html`：页面骨架和样式。
- `build.py`：把 `src/` 拼成 `index.html`（`python3 build.py`）。
- `qa/`：自动化测试脚本（Playwright）、测试结果 JSON 和数据样例；`shots/`：测试截图。

## 已知限制

- 这是一个简化的“玩具模型”，参数是为了好看、好理解而设定的，不代表真实社会的规律。
- 每天的事件日志最多记录 300 条，普通闲聊不记录；只保留“当天”的日志和每个人最近 12 条经历。
- 状态不会自动保存，刷新页面会回到第 0 天（但同一个种子会得到同样的结果）。
